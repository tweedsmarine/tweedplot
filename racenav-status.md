- 29 Oct personal bathymetry phase 1 (Olex / TimeZero PBG style): new crate crates/bathy. Store = SQLite `pbathy\bathy.sqlite` (dev root, else app data; RACENAV_PBATHY_DIR), table tiles(l, ty, tx, n, data) on TimeZero's grid: EPSG:3395 ellipsoidal Mercator quadtree, 256×256-cell tiles, level 16 finest (~1.8 m at 41°S), levels 6–15 built by merging 2×2 cells. Cell = n, mean height (m, +up), m2 (spread), newest hour, source bits (own/PBG/XYZ); Chan merge so imports and tracks add in any order. Blob "TPB1" + count + zlib of 19-byte records. Importers: .tzpbg (zip of SQLite: MX_RCL(r from south, c, l), blob = u8 1, f32 min/max, 00 01 02, u16 n, u32 len, zlib of u8 x, u8 y, f32 z; see project doc pbg-format.md), .dbpbg/.dbwassp, XYZ text (TimeZero export = cell corners). Tracks: Library::for_each_track → clean_depths (7-fix median, 2 m / 10 %) → store; seeded table skips tracks added before (a changed track waits for ✕ All + rebuild). Rendering: /pbathy/z/x/y.png (Web Mercator tiles sampled from the 3395 grid; nearest ≤ z16, bilinear above), rainbow or blues over a depth range (Fit to view = 2nd–98th percentile in view), hillshade, contours by zoom, small-gap fill (2 cells, ≥3 neighbours). App: app/src-tauri/src/pbathy.rs (pbathy_status/pick_file/import/from_tracks/cancel/style/fit/at/clear), app/src/pbathy.js (Chart data › Personal bathymetry; Layers checkbox; cursor readout on the position line). Chris's 20240228.tzpbg: 8.9 M cells imported in 55 s (release), store 400 MB (≈3× the PBG: 19 vs 6 bytes a cell; slim later if needed), z12 tiles ~8 ms. Example: `cargo run -p bathy --release --example bathy_tiles -- <store> <z> <w> <s> <e> <n> <out>`.
