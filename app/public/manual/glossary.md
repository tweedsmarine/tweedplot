# Glossary

Terms used in TweedPlot and in this manual.

| Term | Meaning |
| --- | --- |
| AIFS, AIGFS | Machine-learning global forecast models from ECMWF and NOAA |
| AIS | Automatic Identification System: ships and some buoys broadcast their identity, position, course and speed by VHF radio |
| Analysis | A model's best estimate of the weather at the start of a run, built from observations |
| Apparent wind (AWA, AWS) | The wind felt on the moving boat: true wind combined with the boat's own motion |
| Arrival radius | How close counts as reaching a mark |
| AtoN | Aid to navigation: a buoy, beacon or light; an AIS AtoN broadcasts its own position (a virtual one exists only as a broadcast) |
| Barrier | A line the routing may not cross, a zone it may not enter, or a mark it must keep a set distance from |
| Clearing bearing | A bearing line from a mark that you steer not more or not less than, to keep clear of a danger; labelled in true and magnetic |
| Layline | The line on which a boat can just fetch a mark on one tack; the angle comes from the polar, or a generic tacking angle you set |
| Magnetic variation (VAR) | The angle between true and magnetic north, east positive; from the World Magnetic Model or the chart's charted value |
| Tacking cone | The corridor either side of the direct line to a mark, inside which tacking is efficient when cruising |
| WMM | World Magnetic Model (WMM2025): the standard model of the Earth's magnetic field, used for variation anywhere |
| Bolt hole | A sheltered harbour or anchorage to run to if conditions turn |
| Bridge alert management (BAM) | IMO's rules for how navigation equipment raises and handles alerts: alarm, warning and caution, managed from one place |
| BTW, DTW | Bearing and distance to the next mark |
| CAPE | Convective available potential energy: a measure of how unstable the air is; high values mean squalls and thunderstorms are possible |
| Chart datum | The level charted depths are measured from, close to the lowest tide |
| COG, SOG | Course and speed over the ground (from GPS) |
| Contiguous zone | The belt from 12 to 24 NM off the baseline where a state can enforce customs, immigration and similar laws |
| CPA, TCPA | Closest point of approach: how close another vessel will pass if neither alters; time to CPA: how long until then |
| CSV | A text table with values separated by commas or semicolons (polar files) |
| Day shape | A black ball, cone, cylinder or diamond hoisted by day to show a vessel's status (at anchor, not under command, fishing...); TweedPlot shows the matching shape beside an AIS target |
| Display category | How much of the chart an ECDIS shows: Base (the minimum, never reduced), Standard, or All |
| Dock | The panel along the bottom of the TweedPlot window for tables and graphs |
| Drawer | A panel that slides out from the icon rail |
| ECMWF | European Centre for Medium-Range Weather Forecasts; its main model is the IFS |
| EEZ | Exclusive economic zone: out to 200 NM, where New Zealand controls fishing and other resources |
| Efficiency | The percentage of the polar the routing assumes you sail at |
| ENC | Electronic navigational chart: the official vector chart |
| Ensemble | Many runs of one model from slightly different starts; their spread shows the forecast's uncertainty |
| ETA, TTG | Estimated time of arrival; time to go |
| Fetch | The distance of open water the wind blows over, which limits wave growth |
| FMA | Fisheries management area: one of the areas New Zealand's fisheries are managed and reported by |
| Gate sweep | Routings through each of a row of points, to compare options |
| GFS | Global Forecast System, NOAA's main global model |
| GPX | A common file format for marks, routes and tracks |
| GRIB | Gridded Binary: the standard file format for weather model output |
| GSHHG | A free, detailed world coastline database, used for the coast outside the LINZ charts |
| Gust | A short burst of wind above the average; forecast separately in many GRIBs |
| Hs (significant wave height) | The average height of the highest third of the waves; individual waves can be nearly twice it |
| IALA A | The buoyage system used in New Zealand, Europe and most of the world outside the Americas: red to port entering harbour |
| ICON | The German weather service's (DWD) global model |
| IEC 62288 | The international standard for how navigation displays (radar, ECDIS) present information, including AIS targets |
| Info window | The small movable window that shows the details of what you clicked on the chart |
| Isobar | A line of equal pressure; closer isobars mean stronger wind |
| Isochrone | The line of everywhere the boat can reach after a given time |
| Lead time | How far ahead a forecast is: forecasts lose accuracy with lead time |
| Lidar | Laser surveying from an aircraft; in clear water it measures the seabed too |
| LINZ | Land Information New Zealand, the national hydrographic authority and source of the open chart data |
| Lost target | An AIS target not heard for a while, shown crossed through at its last known position |
| Meteogram | A graph of the forecast at one place over time |
| MMSI | Maritime Mobile Service Identity: the nine-digit number that identifies a vessel's radio and AIS |
| Monitor window | A second TweedPlot window for another screen, showing any view |
| Mātaitai | A customary fishing reserve set up for tangata whenua, closed to commercial fishing |
| NMEA 0183 | The long-standing serial standard for marine instrument data (sentences such as $GPRMC) |
| NOMADS | NOAA's server for model data, which cuts files to the area asked for |
| NZVD2016 | New Zealand Vertical Datum 2016, about mean sea level; land heights and the coastal elevation models use it, unlike charted depths |
| Polar | A table of boat speed against true wind angle and speed |
| Prohibition, restriction | In MPI's rules: a prohibition closes an area to a fishing method (or all fishing); a restriction only limits it |
| Rounding | Which side a mark must be passed on |
| Rule of thirds | Fuel planning: a third out, a third back, a third reserve |
| Rule of twelfths | A rule of thumb for how the tide rises or falls through each hour |
| Run | One start of a weather model, named by its UTC time (e.g. 12Z) |
| S-52, S-57, S-63 | IHO standards: how charts are drawn on screen; the official vector chart format; and its encryption and licensing scheme |
| S-Mode | IMO's guidelines for a standard user interface on navigation equipment: common functions in the same place, one action to the standard display |
| Safety contour | The depth contour drawn bold, separating water too shallow for the boat |
| Safety depth | The least depth the boat will route through: draft plus margins |
| Saildocs | A free service that emails GRIB files in reply to a request email |
| SCAMIN | Scale minimum: the scale below which a chart feature is not drawn |
| Signal K | An open standard and server that collects boat instrument data and shares it with apps |
| Slack water | The short period around the turn of the tide when the stream is weakest |
| Standard display | The Standard display category with the usual options, one press away (Chart › Chart display) |
| Statistical area | A numbered area used for reporting where fish were caught |
| Taiāpure | A local fishery area of special significance to iwi or hapū, managed with the community |
| Territorial sea | The sea within 12 NM of the baseline, part of the country |
| True wind (TWA, TWS, TWD) | The wind over the water: its angle to the boat's heading, its speed, and the direction it blows from |
| UTC, Z | Coordinated Universal Time; weather model times are given in UTC ("12Z") |
| VMC, VMG | Speed made good towards the mark (course), or directly upwind or downwind |
| XTE | Cross-track error: how far the boat is off the line between marks |
| YB | YB Tracking, the satellite tracker used by many ocean and coastal races |
