# Glossary

Terms and abbreviations used in TweedPlot and in this manual.

| Term | Meaning |
| --- | --- |
| Activity card | The small card over the chart that shows a long job (an import, a download, a routing) while it runs and how it went |
| AIFS, AIGFS | Machine-learning global forecast models from ECMWF and NOAA |
| Air draft | The height of the boat's highest point above the waterline, for bridges and overhead cables |
| AIS | Automatic Identification System: ships and some buoys broadcast their identity, position, course and speed by VHF radio |
| AIS-SART, EPIRB-AIS, MOB device | Distress transmitters that show on AIS: a search and rescue transmitter, an emergency position-indicating radio beacon with AIS, and a personal man-overboard beacon |
| Alerts | The box at the bottom of the data panel where alarms, warnings and cautions appear |
| Analysis | A model's best estimate of the weather at the start of a run, built from observations |
| Apparent wind (AWA, AWS) | The wind felt on the moving boat: true wind combined with the boat's own motion |
| Arrival radius | How close counts as reaching a mark |
| AtoN | Aid to navigation: a buoy, beacon or light; an AIS AtoN broadcasts its own position (a virtual one exists only as a broadcast) |
| Barrier | A line the routing may not cross, a zone it may not enter, or a mark it must keep a set distance from |
| Basket | On a longline: the length of line, with its snoods, between two floats |
| Bolt hole | A sheltered harbour or anchorage to run to if conditions turn |
| Bridge alert management (BAM) | IMO's rules for how navigation equipment raises and handles alerts: alarm, warning and caution, managed from one place |
| BSP, STW | Boat speed through the water (from the log), as distinct from speed over the ground. STW is the name IMO uses |
| BTW, DTW | Bearing and distance to the next mark |
| CAPE | Convective available potential energy: a measure of how unstable the air is; high values mean squalls and thunderstorms are possible |
| Card | A titled part of a drawer that opens and closes |
| Catch log | The Library's record of shots, hauls, catches and notes, each with the time, position, depth and sea temperature |
| Cell | One ENC chart file, covering one area at one scale band |
| Cell permit | The key, bought from a chart supplier, that unlocks one encrypted ENC cell for one system until its expiry date |
| Chart datum | The level charted depths are measured from, close to the lowest tide |
| Chlorophyll-a | The green pigment of plankton, measured from satellites; it shows where the sea is productive |
| Class A, class B, class B+ | The kinds of AIS transponder: class A on ships (most power, most often), class B on small craft, and B+ (SOTDMA) between the two |
| Clearing bearing | A bearing line from a mark that you steer not more or not less than, to keep clear of a danger; labelled in true and magnetic |
| COG, SOG | Course and speed over the ground (from GPS) |
| Contiguous zone | The belt from 12 to 24 NM off the baseline where a state can enforce customs, immigration and similar laws |
| Course vector | The line ahead of a target or the boat showing where it will be after a set time at its present course and speed over the ground |
| CPA, TCPA | Closest point of approach: how close another vessel will pass if neither alters; time to CPA: how long until then |
| CSV | A text table with values separated by commas or semicolons (polar files) |
| CTS | Course to steer: the heading that brings the boat back to, and along, the leg |
| Damping | Averaging a reading over a few seconds to steady it |
| Data panel | The column of readings beside the chart: status, own ship, the readings for the view, the cursor and the alerts |
| Day shape | A black ball, cone, cylinder or diamond hoisted by day to show a vessel's status (at anchor, not under command, fishing...); TweedPlot shows the matching shape beside an AIS target |
| Depth package | A file (.tpdepth) of LINZ survey depths prepared by Tweedsmarine for one region or the whole country |
| DGPS, RTK | More accurate kinds of satellite fix: differential GPS (corrected, about a metre) and real-time kinematic (centimetres) |
| Display base | The part of the chart an ECDIS never lets you remove: coastline, the safety contour, dangers, and the scale and north arrow |
| Display category | How much of the chart an ECDIS shows: Base (the minimum, never reduced), Standard, or All |
| Dock | The wide panel under the chart for tables and graphs |
| Drawer | The panel that opens beside the rail when you click one of its icons |
| EBL, VRM | Electronic bearing line and variable range marker: a bearing line and a range ring from the boat (or another point), as on a radar |
| ECDIS | Electronic Chart Display and Information System: the type-approved chart system ships carry in place of paper charts. TweedPlot follows its conventions but is not one |
| ECMWF | European Centre for Medium-Range Weather Forecasts; its main model is the IFS |
| EEZ | Exclusive economic zone: out to 200 NM, where New Zealand controls fishing and other resources |
| Efficiency | The percentage of the polar the routing assumes you sail at |
| Effort map | A heat map of where the boat spent its time at working speeds, made from the tracks |
| ENC | Electronic navigational chart: the official vector chart |
| Ensemble | Many runs of one model from slightly different starts; their spread shows the forecast's uncertainty |
| ETA, TTG | Estimated time of arrival; time to go |
| ETOPO | NOAA's world relief model, used for depth shading away from New Zealand |
| Exchange set | The folder (ENC_ROOT and its catalogue) in which ENC cells and their updates are delivered |
| Failover | Changing automatically to another source of data when the one in use goes quiet |
| Fetch | The distance of open water the wind blows over, which limits wave growth |
| FMA | Fisheries management area: one of the areas New Zealand's fisheries are managed and reported by |
| Gate sweep | Routings through each of a row of points, to compare options |
| GeoPackage | An open database file format for map data (.gpkg); LINZ's chart data and TweedPlot's library both use it |
| GFS | Global Forecast System, NOAA's main global model |
| Go to | A single point to steer to, set from the right-click menu, in place of the route's next mark |
| GPX | A common file format for marks, routes and tracks |
| Great circle | The shortest path between two places on the globe; its compass course changes along the way |
| GRIB | Gridded Binary: the standard file format for weather model output |
| Group | A named set of marks in the library, which can be shown, hidden or locked together |
| GSHHG | A free, detailed world coastline database, used for the coast outside the LINZ charts |
| Gust | A short burst of wind above the average; forecast separately in many GRIBs |
| HAT, LAT | Highest and Lowest Astronomical Tide: the highest and lowest levels the tide is predicted to reach. Clearances are charted above HAT; LAT is close to chart datum |
| HDG, HDT | Heading: the way the bow points, in °T (HDT is the NMEA sentence for a true heading), as distinct from the course over the ground |
| HDOP | Horizontal dilution of precision: how well placed the satellites are for a fix; lower is better |
| Highway | A steering display: a lane in perspective that shifts with the cross-track error, with the course to steer |
| Himawari | Japan's geostationary weather satellite over the western Pacific, the source of the hourly sea temperature |
| hPa, MSLP | Hectopascal, the unit of pressure (the same as a millibar); mean sea-level pressure |
| Hs (significant wave height) | The average height of the highest third of the waves; individual waves can be nearly twice it |
| HYCOM | A US Navy global ocean model: sea temperature, salinity, currents and sea surface height, with a forecast |
| IALA A | The buoyage system used in New Zealand, Europe and most of the world outside the Americas: red to port entering harbour |
| ICON | The German weather service's (DWD) global model |
| IEC 62288 | The international standard for how navigation displays (radar, ECDIS) present information, including AIS targets |
| IHO | International Hydrographic Organization: sets the standards for charts and their display |
| IMO | International Maritime Organization: the UN body that sets the rules for ships and their equipment |
| Info window | The small movable window that shows the details of what you clicked on the chart |
| INT 1 | The international key to the symbols and abbreviations used on paper charts |
| Isobar | A line of equal pressure; closer isobars mean stronger wind |
| Isochrone | The line of everywhere the boat can reach after a given time |
| Isolated danger | A rock, wreck or obstruction shallower than the safety contour with deeper water all round it, shown with a magenta ring and cross |
| KML, KMZ | Google Earth's file formats for places, lines and areas |
| Layline | The line on which a boat can just fetch a mark on one tack; the angle comes from the polar, or a generic tacking angle you set |
| Lead time | How far ahead a forecast is: forecasts lose accuracy with lead time |
| Leg | The part of a route between two marks |
| Lidar | Laser surveying from an aircraft; in clear water it measures the seabed too |
| Light sector | The arc over which a light shows one colour, or is hidden |
| LINZ | Land Information New Zealand, the national hydrographic authority and source of the open chart data |
| Live data view | The view that shows the raw NMEA 0183 sentences as they arrive |
| Lost target | An AIS target not heard for a while, shown crossed through at its last known position |
| Magnetic variation (VAR) | The angle between true and magnetic north, east positive; from the World Magnetic Model or the chart's charted value |
| Mātaitai | A customary fishing reserve set up for tangata whenua, closed to commercial fishing |
| Meteogram | A graph of the forecast at one place over time |
| MMSI | Maritime Mobile Service Identity: the nine-digit number that identifies a vessel's radio and AIS |
| MOB | Man overboard |
| Monitor window | A second TweedPlot window for another screen, showing any view |
| Multibeam | A sonar that measures a swath of depths across the track, used for hydrographic surveys |
| MUR | A daily analysis of sea surface temperature from all the satellites, at about 1 km, from NASA |
| NDBC, METAR | NOAA's National Data Buoy Center, the source of buoy observations; the standard airport weather report |
| NIWA | New Zealand's National Institute of Water and Atmospheric Research; publishes the 250 m bathymetry of the region |
| NMEA 0183 | The long-standing serial standard for marine instrument data (sentences such as $GPRMC) |
| NOMADS | NOAA's server for model data, which cuts files to the area asked for |
| North up | The chart drawn with north at the top, as distinct from turned to another direction |
| NZVD2016 | New Zealand Vertical Datum 2016, about mean sea level; land heights and the coastal elevation models use it, unlike charted depths |
| ORC, VPP | The Offshore Racing Congress, whose rating certificates include a polar; a velocity prediction program, which calculates a polar from a boat's measurements |
| Overscale | Zoomed in beyond the scale a chart was made for: the picture is bigger but no more accurate |
| Own fleet | Your list of boats to pick out among the AIS targets: friends, company vessels, a race fleet |
| Own soundings | A seabed built from the depths your own sounder has logged, and from imported files |
| PBG | TimeZero's file of personal bathymetry (.tzpbg), which TweedPlot can import as own soundings |
| Plugin | A separate program that TweedPlot starts to do one job; encrypted charts need the TweedPlot S-63 Charts plugin |
| Polar | A table of boat speed against true wind angle and speed |
| Prohibition, restriction | In MPI's rules: a prohibition closes an area to a fishing method (or all fishing); a restriction only limits it |
| Protected library (.tplib) | A library file locked with a passphrase, for sharing marks and tracks |
| Rail | The column of icons down the left edge of the window; each opens a drawer |
| Range rings | Circles at set distances round the boat or a mark |
| Rate of turn | How fast a ship is turning, in degrees a minute, sent by class A AIS |
| Relative motion (RM), true motion (TM) | RM: the boat stays put on the screen and the chart moves under it (Follow on). TM: the chart stays put and the boat moves across it |
| Replay | Playing a logged session back in place of the live data |
| Rhumb line | A line of constant compass course: straight on a Mercator chart, slightly longer than the great circle |
| Rounding | Which side a mark must be passed on |
| Rule of thirds | Fuel planning: a third out, a third back, a third reserve |
| Rule of twelfths | A rule of thumb for how the tide rises or falls through each hour |
| Run | One start of a weather model, named by its UTC time (e.g. 12Z) |
| S-101 | The IHO's new ENC standard; TweedPlot draws charts by its portrayal rules |
| S-52, S-57, S-63 | IHO standards: how charts are drawn on screen; the official vector chart format; and its encryption and licensing scheme |
| SA key | The IHO Scheme Administrator's key, which proves that encrypted chart cells come from an approved data server |
| Safety contour | The depth contour drawn bold, separating water too shallow for the boat |
| Safety depth | The least depth the boat will route through: draft plus margins |
| Sag ratio | When shooting a longline, the boat's speed over the line shooter's speed: below 1 the line goes out slack and fishes deeper |
| Saildocs | A free service that emails GRIB files in reply to a request email |
| Scale band | The range of scales a chart is made for: overview, general, coastal, approach, harbour, berthing |
| SCAMIN | Scale minimum: the scale below which a chart feature is not drawn |
| Scope | The length of chain or rode let out when anchored |
| Sea surface height | The height of the sea surface above its long-term mean, with the tide left out; its slopes show eddies and currents |
| Seat | One of the (up to three) computers on a vessel covered by its encrypted-chart licence |
| Secondary port | A place whose tides are worked out from a standard port's by time and height differences |
| Signal K | An open standard and server that collects boat instrument data and shares it with apps |
| Slack water | The short period around the turn of the tide when the stream is weakest |
| Sleeping target | An AIS target that is slow or far away, drawn small or hidden to keep the chart clear |
| S-Mode | IMO's guidelines for a standard user interface on navigation equipment: common functions in the same place, one action to the standard display |
| Snood | The short line carrying one hook on a longline |
| Soak | How long fishing gear was in the water between the shot and the haul |
| Springs, neaps | The tides of greatest range (around new and full moon) and of least range (around the quarters); streams run fastest at springs |
| Standard display | The Standard display category with light sectors, names and soundings: the chart to come back to, one press away (**Standard** at the top of the data panel) |
| Standard port | A port with its own full tide predictions |
| Statistical area | A numbered area used for reporting where fish were caught |
| Status line | The top line of the data panel: the view, live or paused, the chart's orientation and motion, and the scale |
| Swell | Waves that have travelled out of the wind that made them, as distinct from the wind waves raised locally |
| Swing circle | The circle round the anchor that the bow can reach; the anchor alarm sounds when the bow leaves it |
| Tacking cone | The corridor either side of the direct line to a mark, inside which tacking is efficient when cruising |
| Taiāpure | A local fishery area of special significance to iwi or hapū, managed with the community |
| Territorial sea | The sea within 12 NM of the baseline, part of the country |
| TimeZero | A commercial chart plotter program; TweedPlot imports its marks, routes, tracks and personal bathymetry |
| Toolbar | The strip of buttons down the chart's left edge |
| Topo50 | LINZ's 1:50,000 topographic map series, the source of the detailed coastline and the sheet layout of the high-resolution depths |
| Tp | Peak wave period: the period of the most energetic waves |
| Transducer depth | How far below the waterline the depth sounder's transducer is; added to its reading to give the depth of water |
| Trend line | The thin line under a reading in the data panel showing its last three hours |
| Trip | A period at sea in the library; the marks and tracks made in that time belong to it |
| True wind (TWA, TWS, TWD) | The wind over the water: its angle to the boat's heading, its speed, and the direction it blows from |
| Use | What the boat is mostly for (Cruising, Fishing or Racing); it chooses the toolbar's optional buttons and the data panel's starting layout |
| User permit | The code that identifies your system to chart suppliers when you order encrypted charts |
| UTC, Z | Coordinated Universal Time; weather model times are given in UTC ("12Z") |
| View | An arrangement of the screen: Navigation, Planning, Instruments or Live data |
| VMC, VMG | Speed made good towards the mark (course), or directly upwind or downwind |
| Watchdog | The time after which a silenced alarm sounds again if its cause still lasts |
| Waypoint | A position on a route; in TweedPlot, a mark used as one |
| WMM | World Magnetic Model (WMM2025): the standard model of the Earth's magnetic field, used for variation anywhere |
| XTE | Cross-track error: how far the boat is off the line between marks |
| XYZ file | A text file of positions and depths, one sounding to a line |
| YB | YB Tracking, the satellite tracker used by many ocean and coastal races |
